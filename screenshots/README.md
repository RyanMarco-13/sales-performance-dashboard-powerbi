# Screenshots

This folder contains supporting visuals for the Sales Performance Dashboard project.

| File | Description |
|------|-------------|
| `dashboard-overview.png` | Full dashboard view showing all visuals — sales by category, top products, regional performance, profit percentage, monthly trends, and treemap breakdown. |
| `data-model.png` | Star schema data model showing relationships between `FactSales`, `DimProduct`, and `DateTable`. |
| `measures-list.png` | List of DAX measures created in the model (Total Sales, Total Profit, Profit Percentage, Month Growth, Sales Performance, etc.). |

These images are referenced in the main [README.md](../README.md) for visual context.
